# Chatbu Sub-processors

*Last updated: September 6, 2026*

DATALONGA SOLUTIONS LTD, trading as Chatbu (Company No. 16372088, United Kingdom) ("Chatbu") acts as a processor of end-visitor personal data on behalf of its customers (the data controllers), and as a controller of its customers' account data. To deliver the Service, Chatbu engages the following sub-processors. Each sub-processor processes personal data only to the extent necessary for the purpose described below and under its own data protection commitments.

## Infrastructure and core service

| Sub-processor | Purpose | Location |
| --- | --- | --- |
| Amazon Web Services (AWS) | Cloud infrastructure: application hosting, databases, file storage, transactional email delivery | EU (Frankfurt, eu-central-1) |
| Anthropic (via AWS Bedrock) | AI model responses for chatbot conversations | Served via AWS EU regions |
| Stripe | Payment processing and invoicing (card data is handled solely by Stripe) | EU / US |
| Mixpanel | Product analytics (EU data residency) | EU |
| Hostinger | Marketing website hosting (www.chatbu.io) | EU |

## Messaging and verification

| Sub-processor | Purpose | Location |
| --- | --- | --- |
| Twilio | SMS delivery for verification codes (international numbers) | EU / US |
| NETGSM | SMS delivery for verification codes (Türkiye) | Türkiye |

## Optional integrations (active only when the customer connects them)

| Sub-processor | Purpose | Location |
| --- | --- | --- |
| Meta Platforms (WhatsApp, Instagram, Messenger) | Message delivery for connected Meta channels | EU / US |
| Google | Sign-in (OAuth) and Google Calendar appointment integration | EU / US |
| Apple | Sign in with Apple | US |

## Alternative AI model providers

Where enabled by service configuration, chatbot responses may alternatively be generated by OpenAI, DeepSeek, or Groq. The default and primary AI provider is Anthropic via AWS Bedrock (EU).

## Changes to this list

We will update this page when we add or replace a sub-processor. Questions about this list or our data processing practices: **support@chatbu.io**.
